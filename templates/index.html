FAQ

Questions people ask before using Imigi

Is my file stored on the server?

No. The app is designed for secure browser processing, and most tools operate directly in the browser without sending your file to a server.

What file types are supported?

Common supported formats include JPG, PNG, WEBP, PDF, and image-based QR and document captures. The exact support depends on the tool you are using.

Can I scan a document using my phone camera?

Yes. The document scanner and QR scanner support camera capture on supported mobile and desktop browsers.

Do I need to install anything?

No. The experience is built to work in the browser and can also be installed as a PWA for a more app-like experience.
